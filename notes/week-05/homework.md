# Week 5 · Homework

## Before Thursday 8 October

1. Install Git with your agent. Open a terminal in the `bpa347-week5` folder, start the agent and paste:
   ```prompt
   Check whether Git is installed on this computer. If it is not, install it, and tell me every step I have to do myself.
   ```
   Windows: if Windows asks whether the installer may make changes to your device, click **Yes**. Mac: if a window asks to install the command line developer tools, click **Install**; the download takes some minutes.
2. Close the terminal, open a new one in the same folder, start the agent and paste:
   ```prompt
   Run git --version and tell me what it says.
   ```
   The answer is a line that starts with `git version`. If it is not, show the answer to the agent and ask it to fix the installation.
3. Hand in your script by Thursday 8 October, 09:00. Open the [homework submission page](https://bpa347-submit.vercel.app/) and type your student ID, which starts with UC. Under `make_slides.py`, choose the file `make_slides.py` from your `bpa347-week5` folder and click **Submit**. You can submit again; the latest file counts.
